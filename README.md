Today I work at the intersection of **Flutter & Dart**, **Generative AI workflows**, and **high-performance systems**, turning creative ideas into scalable, real-world software.

### 🔭 What I'm working on

- 📱 **Mobile App Development:** Reactive, performant, and clean mobile applications using **Flutter & Dart** with offline-first architectures (e.g., [**NutriForest**](https://github.com/efekkoc/nutriforest), [**Sağlık Saatim**](https://github.com/efekkoc/ilac-hatirlatici)).
- 🤖 **AI & Autonomous Pipelines:** End-to-end automated media studios and GenAI pipelines leveraging **Python** and cutting-edge vision/video models (e.g., [**FlowStudio**](https://github.com/efekkoc/FlowStudio) with Google Flow & Veo 3.1).
- ⚡ **High-Performance & Game Systems:** Designing modless, concurrent server-side plugins and real-time HUD mechanics using **Java 21** and PaperMC (e.g., [**AquaMap**](https://github.com/efekkoc/AquaMap), [**AquaFishing**](https://github.com/efekkoc/AquaFishing)).
- 🧪 **Architecture & Tooling:** Deep-diving into clean architecture, local persistence (Hive, SQLite), and seamless developer workflows.
